# Level plan (30 levels, 6 themes)

Levels 1 and 2 are built. The rest are planned so we can fine-tune the first two before scaling up.

The progression follows multisensory (Orton-Gillingham-style) teaching: **see → trace → write → apply**.
Letter reversals are developmentally normal up to about age 7, so the game builds direction awareness
gently: visual anchors (b = 🛏️ "bed", the left hand makes an "L"), a consistent left colour (sage) and
right colour (sky), forming letters from the correct start point, and lots of low-pressure repetition.
